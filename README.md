## Getting Started
### Dependencies
* Modern Browser
* Node 26.x
### Installing
* Download The Zip
* Or Do ```git clone https://github.com/rehan-kasim/Cards-Portfolio.git``` and ```cd Cards-Portfolio```
### Executing
* Do ```npx serve```
* And open The link You get (Link May Vary)
* Or Simply Just Open ```https://portfolio-src-mu.vercel.app/```
### Customizing
* Change my name to yours add your journey etc
* I have leaved some comments for you
